# 呼吸器道場（Ventilator道場）

一般病棟のための人工呼吸器学習アプリです。
スマホ・タブレット・PCのブラウザで動き、**ホーム画面に追加するとアプリとして使えます**（PWA）。一度開けば、電波の弱い場所でもオフラインで動きます。

## 中身

| タブ | 内容 |
|---|---|
| 道 ホーム | 修行の流れ・帯（進捗）・3つの教え |
| 稽 事前稽古 | 5つの巻（目的／過去・現在・未来／設定とモード／合併症／アラーム）。間違えた問題は解き直し、全問クリアで準備完了証 |
| 講 講義 | 実機（Hamilton）の横で使う講義コンパニオン。ASVの目標換気量計算つき |
| 戦 アラーム | アラーム実戦5本（閉塞・位置ずれ・回路外れ・気胸・気切カニューレ事故抜去） |
| 省 振り返り | 事後チェック12問・振り返り帳 |
| 伝 伝達者 | 病棟で学習会を企画する → セルフチェック → モデルプラン |
| 機 シミュレーター | モード・設定・患者の状態を変えて、圧・換気量・波形の変化を見る |

## ファイル構成

```
index.html             アプリ本体（すべての内容とロジック）
manifest.webmanifest   ホーム画面に追加したときの名前・アイコン
sw.js                  オフライン対応（Service Worker）
icons/                 アプリのアイコン
.github/workflows/     GitHub Pagesへの自動公開設定
```

## GitHubで公開する手順（はじめの1回だけ）

1. GitHubで新しいリポジトリを作る（例：`ventilator-dojo`）。
2. このフォルダの中身をリポジトリの `main` ブランチに入れる。
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にする。
4. 数分待つと **Actions** タブで公開が終わり、次のURLで開けるようになります。
   `https://<GitHubのユーザー名>.github.io/ventilator-dojo/`

以降は、`main` に変更を入れるたびに自動で公開し直されます。

## 内容を直したいとき

- 問題・解説・シナリオは、すべて `index.html` の中の `SCROLLS`（事前稽古）、`SCEN`（アラーム実戦）、`SETTEI`・`MONX`（用語）、`MODEL_PLAN`（モデルプラン）にまとまっています。
- GitHubの画面上で `index.html` を開き、鉛筆マーク（Edit）から直して「Commit changes」すれば反映されます。
- 直したあと、利用者のスマホにすぐ反映させたいときは `sw.js` の `VERSION`（例：`'v1'` → `'v2'`）も上げてください。

## 院内で使う前に確認すること

- **臨床内容の確認**：医師・臨床工学技士・RSTによる内容の確認（画面下にも注記を表示しています）。
- **連絡先**：「伝達者の巻」STEP 4の `（院内PHS番号をここに記載）` を院内の連絡先に書き換える。
  ※GitHub Pagesは**インターネット上に公開**されます。院外に出せない情報（内線番号・個人名など）は書かないか、リポジトリを非公開にしたうえで院内サーバーに置くなどを検討してください。
- **学習記録**：進捗や振り返り帳は、その端末のブラウザ内にだけ保存されます（サーバーには送られません）。端末やブラウザを変えると引き継がれません。

## AI添削・相談Botについて

「伝達者の巻」のAI添削と相談Botは、Claude上（claude.aiのアーティファクト）で開いたときだけ動く機能です。GitHub Pages版では自動的に非表示になり、セルフチェックとモデルプランが使えます。
GitHub Pages版でもAIを使いたい場合は、APIキーをブラウザに置かずに済む中継サーバー（Cloudflare Workersなど）が別途必要です。
